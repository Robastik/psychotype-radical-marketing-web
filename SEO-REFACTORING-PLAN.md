### ❌ Критические проблемы

#### 1. **SEO-архитектура не соответствует семантическому ядру**
- Нет отдельных посадочных страниц под ключевые запросы:
  - `/wildberries/` — "анализ карточки Wildberries"
  - `/ozon/` — "анализ карточки Ozon"
  - `/analiz-kartochki/` — "анализ карточки товара"
  - `/audit-kartochki/` — "аудит карточки товара"
  - `/dizayn-kartochki/` — "дизайн карточки товара"
  - `/ctr-kartochki/` — "увеличить CTR карточки"

#### 2. **Дублирование контента на главной**
- Секция "Научный метод анализа" (строки 54-122) повторяет описание из Hero
- Секция "Визуальный Паспорт" (строки 125-240) дублирует информацию о методе
- Три шага метода описаны дважды: в Hero и в методологии

#### 3. **Guide не оптимизирован для SEO**
- Нет индивидуального Title/Description для каждой статьи
- Нет FAQ блоков
- Нет Related Articles
- Нет авторства и дат публикации
- Нет структурированных данных для статей (Article schema есть, но не используется массово)

#### 4. **Отсутствие внутренней перелинковки**
- Статьи guide не ссылаются на коммерческие страницы
- Нет breadcrumbs на всех страницах
- Нет Related Articles блоков
- Нет CTA-переходов между информационными и коммерческими страницами

#### 5. **Нет FAQ и E-E-A-T сигналов**
- Отсутствуют блоки "Частые вопросы" на коммерческих страницах
- Нет страниц с авторством методологии
- Нет доказательной базы (кейсы, исследования, ограничения метода)

#### 6. **Слабая оптимизация изображений**
- Alt-тексты не всегда содержат ключевые слова
- Нет lazy loading для всех изображдений
- Нет WebP формата

**Митигация:**

- Мониторить трафик после каждого этапа

**Вероятность:** Низкая  
**Митигация:**
- Проверять уникальность контента перед публикацией
- Использовать canonical URLs
- Проверять через Screaming Frog

### Риск 3: Технические ошибки после деплоя
**Вероятность:** Средняя  
**Митигация:**
- Тестировать на staging перед production
- Иметь rollback план
- Мониторить ошибки после деплоя

### Риск 4: Изменения в алгоритмах поисковиков
**Вероятность:** Низкая  
**Митигация:**
- Следовать best practices (Google Webmaster Guidelines)
