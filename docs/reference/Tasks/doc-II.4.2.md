# Документ II.4.2. Признак = единица внимания

**Код:** II.4.2
**Раздел:** II. Метод: три уровня анализа → II.4 Язык видимого: 6 слоёв разложения карточки
**Время чтения:** 3 мин

---

## Суть за 30 секунд

Каждый визуальный элемент на карточке — плашка, иконка, цветовой акцент, рамка — стоит покупателю когнитивных «монет». Добавление «ещё одной плашки» — это не бесплатно: оно увеличивает визуальную сложность и может снизить ICC. Мозг платит вниманием за каждый элемент — и у этого бюджета есть предел.

---

## Основной текст

### Когнитивная цена элемента

При просмотре карточки работает **визуальный поиск** (Treisman, 1980): чем больше конкурирующих элементов, тем дольше и хуже поиск ключевой информации. Каждый новый элемент — это «налог на внимание».

> «Ещё одна плашка» — это не «ещё одна плашка». Это ещё один объект, за который мозг должен конкурировать, ещё один вопрос «на что смотреть?», ещё один микромомент задержки перед тем, как покупатель найдёт цену.

### Открытые и закрытые списки

eyeCARD различает два типа признаков:

- **Открытый список** — все визуальные элементы, которые ИИ может обнаружить на карточке (потенциально неограничен)
- **Закрытый список** — стандартный набор маркеров, по которым классифицируются оси, архетипы и радикалы (конечное множество)

Для расчёта ICC используется закрытый список: подсчитывается количество классифицированных маркеров, а не вообще всех пикселей.

### Когда элемент — полезный, а когда — мусор

| Тип элемента | Когнитивная цена | Окупаемость |
|-------------|-----------------|------------|
| Маркер целевого радикала (напр., trust-бейдж для тревожного) | Средняя | Высокая — закрывает потребность ЦА |
| «Мостик» к вспомогательному радикалу | Средняя | Средняя — расширяет аудиторию |
| Маркер чужого радикала (напр., неон для эпилептоида) | Высокая | Нулевая — создаёт шум |
| Дублирующая информация | Низкая | Нулевая — избыточность (→ [II.5.1]) |

---

## Как на самом деле

❌ **«Больше элементов = больше информации = лучше для покупателя».**
✅ Set-size effect: больше элементов → дольше поиск → хуже распознавание ключевых выгод.

❌ **«Все плашки на карточке равноценны по воздействию».**
✅ Маркер целевого радикала окупает свою когнитивную цену, а маркер чужого — нет.
