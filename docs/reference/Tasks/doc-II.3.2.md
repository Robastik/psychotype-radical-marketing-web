# Документ II.3.2. Три фильтра выбора радикала товара

**Код:** II.3.2
**Раздел:** II. Метод: три уровня анализа → II.3 Уровень 3 — РАДИКАЛЫ
**Время чтения:** 3 мин

---

## Суть за 30 секунд

Как понять, какой радикал «свой» для товара? eyeCARD использует три фильтра: утилитарность/гедонизм (зачем покупают), JTBD («на какую работу нанимают товар») и ценовое позиционирование (масс-маркет тянет к одним радикалам, премиум — к другим). Пересечение трёх фильтров даёт ведущий и вспомогательный радикал.

---

## Основной текст

### Фильтр 1: Утилитарность / Гедонизм

| Ось | Типичный радикал | Пример |
|-----|-----------------|--------|
| Утилитарный (решает задачу) | Эпилептоид, Тревожный | Тонометр, инструменты, бытовая техника |
| Гедонистический (дарит эмоции) | Истероид, Эмотив, Гипертим | Косметика, парфюмерия, сладости |
| Смешанный | Зависит от доминанты | Гаджет: утилитарно для эпилептоида, гедонистично для истероида |

### Фильтр 2: JTBD (Jobs To Be Done)

Какую «работу» нанимают товар выполнять?

| «Работа» | Типичный радикал |
|----------|-----------------|
| «Быть эффективным» | Паранойяльный |
| «Всё контролировать» | Эпилептоид |
| «Привлекать внимание» | Истероид |
| «Понять устройство» | Шизоид |
| «Получить кайф быстро» | Гипертим |
| «Заботиться о близких» | Эмотив |
| «Не ошибиться, не рисковать» | Тревожный |

### Фильтр 3: Ценовое позиционирование

| Ценовой сегмент | Типичные радикалы |
|-----------------|-------------------|
| Эконом | Тревожный (гарантия), Эпилептоид (порядок, характеристики), Славный малый (архетип) |
| Средний | Гипертим (динамика), Эмотив (забота) |
| Премиум | Паранойяльный (статус, результат), Истероид (эффектность) |
| Ниша / хобби | Шизоид (уникальность) |

---

## Как на самом деле

❌ **«По трём фильтрам всегда получается один однозначный радикал».**
✅ Пересечение фильтров часто даёт ведущий + вспомогательный радикал. Это нормально — см. правило 70/30.

❌ **«JTBD — это научный метод с валидацией».**
✅ JTBD — бизнес-концепт **[ГИПОТЕЗА/ФРЕЙМВОРК]**. Критикуется за избыточный акцент на утилитарность.
