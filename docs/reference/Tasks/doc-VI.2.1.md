# Документ VI.2.1. Метод «Один товар — несколько лиц»

**Код:** VI.2.1
**Раздел:** VI. Практика: от паспорта к продажам → VI.2 Сценарий: перепозиционирование на другую аудиторию
**Время чтения:** 5 мин
**Тип:** Практический фреймворк [П]

---

## Суть за 30 секунд

Один и тот же товар может продаваться разным сегментам аудитории — если создать **несколько вариантов карточек** под разные радикалы. Метод «Один товар — несколько лиц» позволяет протестировать, какой сегмент даёт лучшую конверсию, без изменения самого товара. Когда менять дизайн, а когда — ассортиментную стратегию. Готовые варианты карточек/видеообложек под разные радикалы.

---

## Основной текст

### Зачем нужно несколько лиц

Товар может «природно» тяготеть к одному архетипу, но **обслуживать несколько сегментов** аудитории. Например:
- **Робот-пылесос** — природный архетип Маг (технологии, трансформация), но может продаваться как:
  - **Заботливый** (для семей с детьми) — акцент на уют, безопасность, «забота о доме»
  - **Герой** (для мужчин 25–40) — акцент на мощность, преодоление, «победа над грязью»
  - **Маг** (для гиков) — акцент на технологии, «умный дом», «трансформация уборки»

Вместо того чтобы выбирать **один** сегмент, создайте **три** варианта карточек и протестируйте, какой даёт лучшую конверсию.

### Когда менять дизайн, а когда — ассортиментную стратегию

**Меняйте дизайн, если:**
- Товар универсален и может обслуживать несколько сегментов (робот-пылесос, кроссовки, чайник)
- Разные сегменты ищут разные выгоды в одном товаре (семья → уют, гики → технологии, спортсмены → мощность)
- Вы хотите протестировать новый сегмент без изменения товара

**Меняйте ассортиментную стратегию, если:**
- Товар узкоспециализирован и может обслуживать только один сегмент (например, медицинский тонометр — только эпилептоидная аудитория)
- Разные сегменты требуют **разных товаров** (например, «кроссовки для бега» vs «кроссовки для прогулок» — это разные товары, а не разные лица)
- Вы хотите выйти в новую категорию (например, производитель тонометров хочет выйти в категорию «фитнес-гаджеты»)

### 5 шагов метода «Один товар — несколько лиц»

#### Шаг 1. Определите 2–3 целевых сегмента

**Что делать:**
- Откройте выдачу в вашей категории и проанализируйте 10–15 топовых карточек через eyeCARD.
- Найдите **доминирующий радикал** выдачи (например, 8 из 10 карточек — истероидные).
- Найдите **незанятые радикалы** (например, эпилептоидные и тревожные карточки отсутствуют).
- Выберите 2–3 сегмента для тестирования: доминирующий + 1–2 незанятых.

**Пример:** категория «кроссовки» на WB:
- Доминирующий радикал: **Герой** (спорт, преодоление, победа)
- Незанятые радикалы: **Славный малый** (повседневность, комфорт, «свой»), **Эстет** (стиль, мода, «для прогулок»)
- Тест: 3 варианта карточек — Герой, Славный малый, Эстет

#### Шаг 2. Создайте варианты карточек под каждый сегмент

**Что делать:**
- Для каждого сегмента создайте **отдельную карточку** с визуальными маркерами целевого радикала.
- Используйте сводную матрицу радикалов → [III.8.2] для выбора маркеров.
- Меняйте: цветовую гамму, композицию, шрифты, фото-контекст, инфографику, текст описания.

**Пример:** кроссовки Toptrend (WB 264948561):
- **Вариант 1 (Герой):** ракурс low_angle, высокий контраст, диагонали, extra_bold шрифт, слоган «Победа над дистанцией», фото «бегущий человек в движении»
- **Вариант 2 (Славный малый):** ракурс на уровне глаз, бытовые тона (деним, серый), стандартные гротески, слоган «Комфорт на каждый день», фото «человек идёт по улице»
- **Вариант 3 (Эстет):** ракурс макро, бордо/нюд/золото, S-изгибы, антиква, слоган «Стиль в каждом шаге», фото «кроссовки на полке бутика»

#### Шаг 3. Создайте варианты видеообложек

**Что делать:**
- Для каждого сегмента создайте **отдельную видеообложку** (5–10 секунд) с визуальными маркерами целевого радикала.
- Меняйте: ракурсы, движение, музыку, текст на экране.

**Пример:** кроссовки:
- **Вариант 1 (Герой):** динамичное движение, низкий ракурс, быстрая музыка, текст «ПРЕОДОЛЕЙ»
- **Вариант 2 (Славный малый):** спокойная ходьба, ракурс на уровне глаз, нейтральная музыка, текст «КОМФОРТ»
- **Вариант 3 (Эстет):** медленное панорамирование, макро, классическая музыка, текст «СТИЛЬ»

#### Шаг 4. Запустите A/B-тест

**Что делать:**
- Загрузите все варианты карточек на маркетплейс (если площадка поддерживает A/B-тесты) или используйте разные артикулы.
- Запустите рекламу с разными креативами под каждый сегмент.
- Измеряйте: CTR (кликабельность), CR (конверсия в корзину), CPA (стоимость привлечения).

**Регламент теста:**
- **Длительность:** 7–14 дней (чтобы собрать достаточную статистику)
- **Минимальная выборка:** 1000 показов на вариант
- **Критерий успеха:** вариант с максимальным CR при приемлемом CPA

#### Шаг 5. Масштабируйте победителя

**Что делать:**
- После теста выберите вариант с лучшим CR.
- Масштабируйте его: используйте как основную карточку, создайте похожие варианты для других товаров.
- Проигравшие варианты не удаляйте — используйте как **резервные** для других сегментов.

**Пример:** если вариант «Славный малый» дал CR 3,5%, а «Герой» — 2,1%, «Эстет» — 1,8%:
- Основная карточка: «Славный малый»
- Резервные карточки: «Герой» (для спортивной аудитории), «Эстет» (для модной аудитории)

## Частые ошибки

1. **Создавать слишком много вариантов** — 2–3 варианта достаточно. Больше = размывание бюджета на тесты.

2. **Менять только цвет, не меняя остальное** — радикал считывается через **комплекс маркеров** (цвет + композиция + шрифты + фото + текст). Меняйте всё.

3. **Тестировать меньше 7 дней** — нужно собрать достаточную статистику. Меньше 7 дней = недостоверные результаты.

4. **Игнорировать проигравшие варианты** — они могут пригодиться для других сегментов или других товаров.

## Шаблон плана перепозиционирования

```
□ Шаг 1: Определены 2–3 целевых сегмента
□ Шаг 2: Созданы варианты карточек под каждый сегмент
□ Шаг 3: Созданы варианты видеообложек под каждый сегмент
□ Шаг 4: Запущен A/B-тест (7–14 дней, 1000+ показов на вариант)
□ Шаг 5: Выбран победитель, масштабирован
```
