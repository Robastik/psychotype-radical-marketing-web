### Шпаргалка №3: Декодер паспорта

**Формат:** A4, книжная ориентация
**Содержание:** Как читать каждый блок Визуального паспорта (подробный разбор → [V.1])

#### Блок 1: Шапка
- **Товар:** название, артикул, площадка
- **Дата анализа:** когда был проведён анализ
- **Версия методики:** какая версия eyeCARD использовалась

#### Блок 2: Когнитивный комфорт (ICC)
- **ICC:** 0–100
  - 0–25 — ПЛОХАЯ 🔴 (визуальный хаос)
  - 25–50 — СЛАБЫЙ 🟠 (много шума)
  - 50–75 — СРЕДНИЙ 🟡 (приемлемо, есть запас)
  - 75–100 — ХОРОШИЙ 🟢 (чистый дизайн)
- **Что делать:** если ICC < 50, уменьшите количество элементов, упростите композицию

#### Блок 3: Легенда «ИДЕАЛ / ФАКТ»
- **ИДЕАЛ (Целевая аудитория):** психотип покупателя — пунктирная кобальтовая стрелка
- **ФАКТ (Дизайн):** психотип, который транслирует карточка — сплошная оранжевая линия
- **Что делать:** сравнивайте радары во всех блоках — чем ближе ФАКТ к ИДЕАЛУ, тем лучше

#### Блок 4: СМЫСЛЫ (4 оси)
- **Ось 1:** Структура: Стабильность ↔ Изменения (вектор start→end)
- **Ось 2:** Социальность: Индивидуализм ↔ Принадлежность
- **Ось 3:** Реализация: Мастерство ↔ Служение
- **Ось 4:** Ментальность: Рациональность ↔ Эмоциональность
- **СИГНАЛ:** ЭТАЛОННЫЙ / УВЕРЕННЫЙ / УМЕРЕННЫЙ / СМЕШАННЫЙ
- **Что делать:** если СИГНАЛ СМЕШАННЫЙ, проверьте дилюзию (противоположные маркеры)

#### Блок 5: АРХЕТИПЫ (12 архетипов)
- **Основной архетип:** какую «роль» играет товар
- **Оттеночный архетип:** вторичная «роль»
- **Радар архетипов:** визуализация распределения (ИДЕАЛ vs ФАКТ)
- **Что делать:** если архетип не соответствует товару, пересмотрите позиционирование

#### Блок 6: РАДИКАЛЫ (7 радикалов)
- **Доминирующий радикал:** основной психотип аудитории
- **Вспомогательный радикал:** вторичный психотип
- **Разрыв ИДЕАЛ/ФАКТ:** расхождение между природой товара и дизайном
- **Что делать:** если разрыв критический (Delta >30 или инверсия полюса), измените дизайн под целевой радикал

#### Блок 7: Вердикт
- **СООТВЕТСТВУЕТ** — дизайн конгруэнтен психотипу
- **ЧАСТИЧНО СООТВЕТСТВУЕТ** — есть разрывы, но основа правильная
- **ПРОТИВОРЕЧИТ** — дизайн не соответствует психотипу
- **Что делать:** если ПРОТИВОРЕЧИТ, используйте фреймворк [VI.1.1]

#### Блок 8: QR-код «Методика»
- **Ссылка:** ведёт на справочник eyeCARD (быстрый вход в методику, начните с [V.1])
- **Что делать:** покажите клиентам/коллегам для объяснения метода

### Шпаргалка №4: Чек-лист «7 шагов редизайна»

**Формат:** A5, книжная ориентация

```
□ Шаг 1: Проверьте ICC (должен быть ≥50, цель — 75+)
□ Шаг 2: Определите целевой радикал (из паспорта)
□ Шаг 3: Определите целевой архетип (из паспорта)
□ Шаг 4: Проверьте конгруэнтность (визуал ↔ радикал ↔ архетип)
□ Шаг 5: Приоритет правок: смысл → архетип → радикал → шум
□ Шаг 6: Внесите правки (используйте матрицу радикалов)
□ Шаг 7: Проверьте результат повторным анализом
```

## Как распечатать

Страницы справочника адаптированы для печати: откройте нужную шпаргалку и нажмите Ctrl+P (⌘+P на Mac) — боковая панель и элементы навигации будут скрыты автоматически, таблицы поместятся на лист.

---

## Что делать

1. **Откройте нужную шпаргалку** и распечатайте её через браузер (A4 или A5).
2. **Держите под рукой** при работе с карточками.
3. **Используйте как чек-лист** при создании/улучшении карточек.
4. **Поделитесь с командой** (дизайнеры, копирайтеры, маркетологи) — отправьте ссылку на страницу справочника.
