# Документ VIII.3.3. Социальное доказательство в дизайне карточек: отзывы, рейтинги, «бестселлер»

**Код:** VIII.3.3  
**Раздел:** VIII. Мифы и социальное доказательство → VIII.3 Социальное доказательство  
**Время чтения:** 5 мин

---

## Суть за 30 секунд

Социальное доказательство (social proof) — механизм, при котором люди ориентируются на действия других в условиях неопределённости. В карточке товара оно проявляется в рейтингах, отзывах, метках «бестселлер», «популярное». Доказано: Cialdini (1984), Asch (1951). Эффект сильнее, когда доказательство **правдоподобно** и **релевантно** аудитории. Подделки уничтожают доверие.

---

## Основной текст

### Что такое социальное доказательство

**Определение:**

> «Социальное доказательство — это психологический феномен, при котором люди копируют поведение других в условиях неопределённости, предполагая, что окружающие знают больше.»  
> — Cialdini R. (1984). *Influence: The Psychology of Persuasion*. Chapter 4.

**Классический эксперимент:**

**Asch S. (1951). «Effects of group pressure upon the modification and distortion of judgments.»**

**Дизайн:**
- Участникам показывали три линии разной длины
- Задача: выбрать линию, равную по длину стандартной
- В группе были «акторы», которые намеренно выбирали неправильный ответ
- Результат: 75% участников соглашались с неправильным ответом группы хотя бы раз

**Вывод:** мнение группы влияет на индивидуальное суждение, даже когда индивид уверен в правильном ответе.

### Социальное доказательство в карточке товара

**Маркетплейсы используют социальное доказательство на уровне платформы:**

| Элемент | Как работает | Статус |
|---------|--------------|--------|
| **Рейтинг** | 4.8/5 звёзд → товар качественный | [ДОКАЗАНО] |
| **Количество отзывов** | 1234 отзыва → товар популярен | [ДОКАЗАНО] |
| **Метка «бестселлер»** | Покупают другие → товар хороший | [ПОДДЕРЖАНО] |
| **Метка «популярное»** | Высокий спрос → нужно поторопиться | [ПОДДЕРЖАНО] |
| **Фото в отзывах** | Реальные люди используют товар | [ПОДДЕРЖАНО] |
| **Видео в отзывах** | Ещё больше правдоподобия | [ПОДДЕРЖАНО] |
| **«Купили вместе»** | Другие покупают с этим → комплект | [ДОКАЗАНО] |

### Механизм: почему это работает

**Неопределённость → эвристика «другие знают лучше»**

Когда покупатель:
1. Не может оценить качество товара (сложный/новый товар)
2. Не хочет рисковать (дорогой товар)
3. Спешит (низкая вовлечённость)

→ он использует **социальное доказательство** как сигнал качества.

**Пример:**
- **Товар A:** 4.8/5, 1234 отзыва, «бестселлер»
- **Товар B:** 3.2/5, 12 отзывов

Покупатель выберет **А**, даже если не знает реальные характеристики товаров.

### Социальное доказательство по радикалам

| Радикал | Какая соцдока работает | Пример |
|---------|------------------------|--------|
| **Паранойяльный** | Детальные отзывы с фактами, сертификаты, сравнительные тесты | «Сравнил с A&D Medical, разница в погрешности 0.5%» |
| **Эпилептоид** | Гарантия, экспертные отзывы, официальные документы | «Сертификат ГОСТ, гарантия 5 лет» |
| **Истероид** | Яркие фото в отзывах, хайп, «вирусность» | «Все друзья спрашивают, где купил!» |
| **Шизоид** | Независимые обзоры, ссылки на источники, «сравнение с аналогами» | «Обзор на YouTube, ссылка в описании» |
| **Гипертим** | Много фото/видео, живые эмоции, «рекомендую всем!» | «Купила и не пожалела! Супер!» |
| **Эмотив** | Отзывы с историями, семейные фото, «для близких» | «Купила маме, она в восторге!» |
| **Тревожный** | Детальные отзывы о надёжности, доставке, гарантии | «Пришло быстро, всё работает, упаковка целая» |

### Правдоподобие — главное условие

**Социальное доказательство работает, только если покупатель верит.**

| Фактор правдоподобия | Пример хорошо | Пример плохо |
|----------------------|---------------|--------------|
| **Количество отзывов соответствует продажам** | 1000 отзывов, 1000 продаж | 1000 отзывов, 50 продаж |
| **Отзывы разные** | Несколько фото, разные тексты | Одинаковые фразы, похожие имена |
| **Есть фото/видео** | Реальные фото товара | Только текст, без подробностей |
| **Есть негативные отзывы** | 4.7/5 с несколькими 3* отзывами | 5.0/5, все отзывы идеальные |
| **Ответ продавца на негатив** | «Спасибо за обратную связь, решили проблему» | Игнорирование негатива |
| **Релевантность аудитории** | Отзывы от мам с детьми (детское питание) | Отзывы от мужчин (косметика) |

### Парадокс: негативные отзывы повышают доверие

**Исследования:**
- Покупатели **не доверяют** товарам с 5.0/5
- Оптимальный рейтинг: **4.2–4.8/5**
- Небольшое количество негативных отзывов повышает правдоподобие

**Почему:**
- 5.0/5 выглядит подозрительно (накрашено)
- 4.5/5 с парой негативных отзывов — «реальный» товар
- Покупатель думает: «Если есть пара недовольных, но большинство довольно — значит, товар реальный»

### Социальное доказательство в разных блоках карточки

| Блок карточки | Как использовать соцдоку |
|---------------|--------------------------|
| **Главное изображение** | Рейтинг на миниатюре (если площадка позволяет), метка «бестселлер» |
| **Заголовок** | «Бестселлер», «популярное», «1000+ покупателей» |
| **Цена** | «Было/стало» + количество покупок |
| **Галерея** | Фото от покупателей, видео-отзывы |
| **Описание** | «1000+ покупателей», «4.8/5 по 1234 отзывам» |
| **Блок отзывов** | Подробные отзывы с фото/видео |
| **Блок «Купили вместе»** | «Покупатели также купили» |
| **Блок «Популярные в категории»** | «Топ-10 в категории» |

### Эффект владения (endowment effect)

**Источник:** Thaler R. (1980). «Toward a positive theory of consumer choice.» *Journal of Economic Behavior & Organization*.

**Суть:** люди переоценивают то, чем владеют (или считают, что владеют).

**Применение в карточке:**
- «Добавьте в корзину, чтобы забронировать» — создаёт ощущение владения
- «Товар в вашей корзине ожидает оформления» — «я уже почти купил»
- Бесплатная доставка при заказе от суммы — «я уже вложил деньги, не хочу тереть»

### Как на самом деле

❌ **«Чем больше отзывов, тем лучше»**  
✅ Важна не только **количество**, но и **качество** отзывов. 1000 накрученных отзывов хуже, чем 50 реальных.

❌ **«Рейтинг 5.0/5 — идеально»**  
✅ Рейтинг 5.0/5 вызывает недоверие. Оптимально: 4.2–4.8/5.

❌ **«Социальное доказательство работает для всех»**  
✅ Эффект сильнее для тревожного радикала (нужна уверенность) и слабее для истероидного (он сам хочет быть первым).

---

## Что делать

1. **Собирайте реальные отзывы** — просите покупателей оставлять фото/видео.

2. **Отвечайте на негатив** — даже если отзыв несправедлив, ответ повышает доверие.

3. **Не накручивайте** — фейковые отзывы разрушают доверие.

4. **Подбирайте соцдоку под радикал** — для Эпилептоида — сертификаты, для Истероида — яркие фото, для Тревожного — детальные отзывы.

5. **Используйте метки осторожно** — «бестселлер» работает, только если правда.
