## Основной текст

### Триколор (patriotic tricolor)

Маркер `patriotic tricolor` (флаг РФ, триколор, бело-сине-красные ленты/элементы) — один из самых частых культурных кодов на российских маркетплейсах. Его смысл зависит от контекста подачи:

| Контекст подачи | Архетип / Радикал / Ось | Смысл |
|----------------|-------------------------|-------|
| Строгая графика (геральдика, ГОСТ, сертификаты) | Правитель / Эпилептоид / Стабильность + Рациональность | Символ порядка, закона, легитимности |
| Масштаб и национальная идея | Правитель / Паранойяльный / Мастерство | Маркер сопричастности к большому делу |
| «Наш», местный, надёжный | Славный малый / Тревожный / Принадлежность | Остров безопасности, гарантия «не исчезнет завтра» |
| Динамичная подача (развевающийся флаг, мазки) | Герой / — (архетип) / Изменения | Символ победы и преодоления |

> Триколор — это не «просто цвета». Его считывание полностью зависит от того, какие ещё маркеры его окружают: строгая рамка с ГОСТ → порядок и легитимность; динамичные мазки → победа и драйв.

### ГОСТ и сертификаты

ГОСТ-маркировка на карточке работает как маркер **Эпилептоида** (порядок, регламент) и полюса **Рациональность** (доказательность, стандарт). Для тревожного покупателя ГОСТ — «официальная гарантия, что товар не развалится». Для истероида — «скучно, не про меня».

### «Лабораторный свет»

Холодный белый свет, чистый спектральный синий фон — маркер полюса **Рациональность** и архетипа **Мудрец**. Считывается как «научный, доказанный, точный». Работает для медицинские товаров, сложной техники, БАДов. Противопоказан для эмоциональных категорий (косметика, игрушки).

## Как на самом деле

❌ **«Триколор на карточке всегда означает "патриотизм"».**
✅ Смысл триколора зависит от контекста подачи: строгая графика → порядок/легитимность, динамичная → победа, бытовая → «свой, местный».

❌ **«Культурные коды универсальны для всех стран».**
✅ Культурные коды по определению локальны. ГОСТ не несёт смысла за пределами СНГ.
