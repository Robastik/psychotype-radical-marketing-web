## Суть за 30 секунд

Текст описания товара — не просто перечень характеристик, а **психологический крючок**, который цепляет целевой радикал аудитории. Фреймворк «Описание на языке психотипа» даёт структуру текста (первое предложение = крючок радикала), слова-триггеры по 7 радикалам и запретные конструкции. Таблицы триггеров готовы к дословному использованию в копирайтинге.

---

## Основной текст

### Структура текста описания

**Формула:** `[Крючок радикала] + [Ключевая выгода] + [Характеристики] + [Призыв к действию]`

**Пример для Эпилептоида:**
- **Крючок:** «Надёжность, проверенная временем.»
- **Ключевая выгода:** «Тонометр [название] — точные измерения без погрешностей.»
- **Характеристики:** «Сертифицирован по ГОСТ, гарантия 5 лет, автоматическая калибровка.»
- **Призыв к действию:** «Закажите сейчас и получите точность, которой можно доверять.»

**Пример для Истероида:**
- **Крючок:** «Будь в центре внимания.»
- **Ключевая выгода:** «[Название] — не просто косметика, а твой личный стилист.»
- **Характеристики:** «Лимитированная коллекция, эксклюзивная формула, глянец и блеск.»
- **Призыв к действию:** «Успей забрать свою баночку — количество ограничено!»

| **Тревожный** | «Безопасность прежде всего.» / «Гарантия, которой можно доверять.» | Надёжность, предсказуемость, инструкция, «как у всех, только лучше» | «Риск», «эксперимент», «новинка» |

### Запретные конструкции (для всех радикалов)

1. **«Мы предлагаем»** — пассивная конструкция, которая не цепляет. Вместо этого: «[Товар] — это...»

2. **«Высокое качество»** — пустая фраза, которая не несёт смысла. Вместо этого: «Сертифицирован по ГОСТ» (Эпилептоид) или «Эксклюзивная формула» (Истероид).

3. **«Инновационный продукт»** — клише, которое не работает. Вместо этого: «Технология, которая меняет правила» (Шизоид) или «Новинка, которую все ждут» (Истероид).

4. **«Подходит для всех»** — попытка угодить всем = угодить никому. Вместо этого: «Создан для [целевой радикал]».

5. **«Может быть»** / **«возможно»** — неуверенные конструкции, которые отталкивают Паранойяльного и Тревожного. Вместо этого: «Гарантированно» / «точно».

## Кейс: переписываем описание для Эпилептоида

**Исходный текст (универсальный):**
> «Мы предлагаем высококачественный тонометр, который подходит для всей семьи. Инновационный продукт с гарантией качества.»

**Проблемы:**
- «Мы предлагаем» — пассивная конструкция
- «Высококачественный» — пустая фраза
- «Подходит для всех» — попытка угодить всем
- «Инновационный продукт» — клише
- «Гарантия качества» — абстракция

**Переписанный текст (Эпилептоид):**
> «Надёжность в каждой детали. Тонометр [название] — точные измерения без погрешностей. Сертифицирован по ГОСТ, гарантия 5 лет, автоматическая калибровка. Закажите сейчас и получите точность, которой можно доверять.»

**Что изменилось:**
- **Крючок:** «Надёжность в каждой детали» — цепляет Эпилептоида
- **Ключевая выгода:** «точные измерения без погрешностей» — конкретика
- **Характеристики:** «Сертифицирован по ГОСТ, гарантия 5 лет, автоматическая калибровка» — факты, а не абстракции
- **Призыв к действию:** «Закажите сейчас и получите точность, которой можно доверять» — императив + гарантия

## Шаблон чек-листа описания

```
□ Первое предложение = крючок радикала (см. таблицу триггеров)
□ Ключевая выгода конкретна (не «высокое качество», а «гарантия 5 лет»)
□ Характеристики в формате фактов (не «инновационный», а «технология X»)
□ Призыв к действию в императиве («Закажите», не «Вы можете заказать»)
□ Нет запретных конструкций («мы предлагаем», «может быть», «подходит для всех»)
□ Инфографика соответствует радикалу (см. таблицу инфографики)
```
