# Документ VI.4.1. От паспорта к кластерам: мост между дизайном и семантикой

**Тип:** Практический фреймворк [П]

---

## Суть за 30 секунд

Визуальный паспорт eyeCARD — не только про дизайн, но и про **семантику рекламы**. Ведущий радикал товара определяет типы поисковых запросов (функциональные/эмоциональные/брендовые), структуру рекламных кампаний Ozon/WB и согласование объявления с креативом карточки. Фреймворк превращает паспорт в готовую стратегию рекламы: от подбора ключевых слов до написания заголовков объявлений.

## Основной текст

### Логика: радикал → типы запросов → структура кампаний

**Цепочка:**
1. **Ведущий радикал товара** (из паспорта) → определяет, **как** покупатели ищут товар
2. **Типы запросов** (функциональные/эмоциональные/брендовые) → определяют структуру кампаний
3. **Согласование объявления и креатива** → обеспечивает «бесшовность» от клика до покупки

### Структура кампаний Ozon/WB по радикалам

**Ozon:**
- **Трафареты** — функциональные запросы (карточка товара в поиске)
- **Продвижение в поиске** — эмоциональные запросы (повышение позиции)
- **Видеообложки** — эмоциональные запросы (привлечение внимания)

**Wildberries:**
- **Автоматические кампании** — функциональные запросы (карточка в поиске)
- **Реклама в поиске** — эмоциональные запросы (повышение позиции)
- **Реклама в карточке товара** — брендовые запросы (кросс-продажи)

### Согласование объявления и креатива карточки

**Правило бесшовности:** заголовок объявления + креатив карточки + текст описания должны говорить **на одном языке радикала**.

**Пример для Эпилептоида:**
- **Заголовок объявления:** «Тонометр [название] — надёжность, проверенная временем»
- **Креатив карточки:** матовые фактуры, строгая сетка, таблица характеристик, бейдж «ГОСТ»
- **Текст описания:** «Надёжность в каждой детали. Сертифицирован по ГОСТ, гарантия 5 лет.»

**Пример для Истероида:**
- **Заголовок объявления:** «Новинка! [Название] — эксклюзивная коллекция»
- **Креатив карточки:** яркость, глянец, 3D-эффекты, звёзды
- **Текст описания:** «Будь в центре внимания. Лимитированная коллекция, эксклюзивная формула.»

### 5 шагов: от паспорта к кластерам

#### Шаг 1. Определите ведущий радикал товара

**Что делать:**
- Откройте паспорт товара в eyeCARD.
- Найдите блок «РАДИКАЛЫ» — какой радикал доминирует на ИДЕАЛе?
- Запишите ведущий радикал (например, Эпилептоид).

#### Шаг 2. Соберите семантические кластеры по радикалу

**Что делать:**
- Используйте таблицу «радикал → типы запросов» для сбора ключевых слов.
- Разделите запросы на три кластера: функциональные, эмоциональные, брендовые.
- Используйте Wordstat (Яндекс) или аналогичный инструмент для проверки частотности.

**Пример для Эпилептоида:**
- **Функциональные:** «тонометр характеристики», «тонометр ГОСТ», «тонометр сертификат»
- **Эмоциональные:** «надёжный тонометр», «тонометр гарантия»
- **Брендовые:** «[название бренда] качество», «[название бренда] надёжность»

#### Шаг 3. Создайте структуру кампаний

**Что делать:**
- Для каждого кластера создайте отдельную кампанию на Ozon/WB.
- Используйте таблицу «радикал → структура кампаний» для выбора типов кампаний.
- Установите ставки в зависимости от частотности запросов.

**Пример для Эпилептоида:**
- **Трафареты / Автоматические:** функциональные запросы («тонометр характеристики»)
- **Продвижение в поиске:** эмоциональные запросы («надёжный тонометр»)
- **Видеообложки / Реклама в карточке:** брендовые запросы («[бренд] качество»)

#### Шаг 4. Напишите заголовки объявлений

**Что делать:**
- Используйте таблицу слов-триггеров из VI.3.1 для написания заголовков.
- Заголовок должен начинаться с крючка радикала.
- Длина заголовка: до 60 символов для Ozon, до 100 символов для WB.

**Пример для Эпилептоида:**
- **Заголовок Ozon:** «Тонометр [название] — надёжность в каждой детали»
- **Заголовок WB:** «Тонометр [название] — надёжность, проверенная временем. Сертификат ГОСТ, гарантия 5 лет.»

#### Шаг 5. Проверьте бесшовность

**Что делать:**
- Откройте объявление и креатив карточки рядом.
- Проверьте: заголовок объявления + креатив карточки + текст описания говорят на одном языке радикала?
- Если нет — перепишите заголовок или измените креатив.

**Чек-лист бесшовности:**
- [ ] Заголовок объявления начинается с крючка радикала
- [ ] Креатив карточки содержит визуальные маркеры радикала
- [ ] Текст описания использует слова-триггеры радикала
- [ ] Все три элемента говорят на одном языке

## Кейс: креативы под два радикала одной ниши

**Товар:** кроссовки Toptrend (WB 264948561)

**Сегмент 1: Герой (спортсмены)**
- **Заголовок объявления:** «Победа над дистанцией. Кроссовки Toptrend — для настоящих героев.»
- **Креатив карточки:** ракурс low_angle, высокий контраст, диагонали, extra_bold шрифт
- **Ключевые слова:** «кроссовки для бега», «спортивные кроссовки», «кроссовки для победы»

**Сегмент 2: Славный малый (повседневность)**
- **Заголовок объявления:** «Комфорт на каждый день. Кроссовки Toptrend — твой надёжный спутник.»
- **Креатив карточки:** ракурс на уровне глаз, бытовые тона (деним, серый), стандартные гротески
- **Ключевые слова:** «кроссовки на каждый день», «удобные кроссовки», «кроссовки для прогулок»

**Результат:** два разных объявления ведут на **одну и ту же карточку товара**, но креативы адаптированы под разные сегменты. Это позволяет охватить две аудитории без изменения товара.
