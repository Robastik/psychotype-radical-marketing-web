## Суть за 30 секунд

Как характер покупателя «считывается» с карточки? Каждый радикал имеет свою визуальную сигнатуру по 6 слоям — от цветовой гаммы до фото-сюжета. Эти маркеры — авторская операционализация eyeCARD **[ГИПОТЕЗА/ФРЕЙМВОРК]**, созданная на основе прикладной характерологии и проверенная на сотнях реальных карточек.

### Как пользоваться маркерами

1. Определите ведущий радикал целевой аудитории (по отзывам → [III.0.2] или по паспорту → [V.4.1])
2. Выберите столбец — это ваш язык дизайна
3. Для вспомогательного радикала возьмите 1–2 ячейки из другого столбца
4. Проверьте: нет ли в карточке маркеров, принадлежащих радикалу, **противоположному** вашему целевому?

> Достаточно 3–4 ключевых маркеров. Карточка — это не инструкция по сборке, а визуальный сигнал.

---

## Как на самом деле

❌ **«Нужно использовать ВСЕ маркеры из столбца — иначе радикал не сработает».**
✅ Достаточно 3–4 ключевых маркеров. Полная матрица → [III.8.2].

❌ **«Один и тот же маркер может быть только у одного радикала».**
✅ Кросс-радикальность нормальна: trust-бейджи работают и для паранойяльного, и для тревожного, и для эпилептоида. Важен контекст.
