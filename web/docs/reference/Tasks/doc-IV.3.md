# Документ IV.3. ИСКАТЕЛЬ (Explorer)

**Код:** IV.3
**Раздел:** IV. Атлас смыслов: 12 архетипов → Независимость
**Время чтения:** 3 мин

---

## Суть за 30 секунд

Исследователь — архетип свободы и открытия. Товар «как рюкзак за горизонт»: тур-снаряжение, навигация, походная одежда. Визуал: хаки, охра, терракотовый, грубые текстуры, ломаные линии природы. Тень: бесцельное скитание, изоляция.

---

## Роль

| Параметр | Описание |
|----------|----------|
| Базовая цель | Найти себя через мир |
| Стратегия | Путешествовать, пробовать новое |
| Теневая сторона | Бесцельное скитание, изоляция |
| Квадрант | Независимость |

## Категории-носители

Тур-снаряжение, термосы, навигаторы и GPS, походная одежда, туристические карты, мультитулы.

## Визуальная сигнатура

| Слой | Маркеры |
|------|---------|
| **Хроматика** | Хаки, охра, терракотовый, эффект выцветания (faded), землистые оттенки |
| **Морфология** | Грубые текстуры (камень, брезент, кора дерева), ломаные естественные линии, неровные края |
| **Типографика** | Stencil, typewriter, bold weight, функциональные гротески |
| **Архитектоника** | Rule of thirds, высокая пустота, фокус: фон/контекст |
| **Графика** | Technical_schemes, карты, знаки прочности/маркировки, условные обозначения |
| **Сюжет** | Lifestyle (outdoor), вид под углом (angled), динамическая поза, демонстрация в использовании |

## Речевые формулы

**Триггеры:** «Свобода», «Дорога», «Открой», «Испытай», «Для приключений».
**Запрещённые:** «Стабильность», «Гарантия», «Как у всех» — эти слова убивают импульс к исследованию.

## Мини-кейс

**Термос, Ozon.** Было: белый фон, изолят, «Надёжный термос для дома». Статус: НЕПРОЧНОСТЬ сигнала Исследователя.

Правка: фон с горами на рассвете, stencil-шрифт, патч «24 часа тепла», текст «Пусть дорога будет горячей. 24 часа тепла в любом походе».

---

## Как на самом деле

❌ **«Исследователь — это про активный отдых».**
✅ Исследователь — про внутреннее путешествие, а не хобби. Внешняя активность — лишь форма поиска себя.

❌ **« rugged-эстетика = мужская аудитория».**
✅ Грубые текстуры и землистая палитра говорят всем, кто чувствует зов горизонта — гендерной привязки нет.
