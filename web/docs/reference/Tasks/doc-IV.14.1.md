## Суть за 30 секунд

Алгоритм выбора архетипа: функция → мотивация → ось → архетип. Проверка через «комментариевый» блок паспорта: если покупатели пишут «надёжный» — это Стабильность, «кайф» — Эмоциональность. Выбор архетипа = выбор сегмента, а не объективная истина.

---

## Основной текст

### [П] Алгоритм выбора архетипа

**Шаг 1: Функция товара**
Что товар делает в жизни покупателя?

| Функция | Ось смыслов | Квадрант |
|---------|------------|----------|
| Защищает, заботится | Служение + Принадлежность | Стабильность |
| Преодолевает, побеждает | Мастерство + Индивидуализм | Риск/Мастерство |
| Объединяет, развлекает | Принадлежность + Эмоциональность | Принадлежность |
| Познаёт, открывает | Индивидуализм + Рациональность | Независимость |

**Шаг 2: Мотивация ЦА (по отзывам)**
На что покупатели обращают внимание в отзывах?

| Частые слова в отзывах | Доминирующая мотивация |
|------------------------|----------------------|
| «Надёжный», «проверенный», «как описано» | Стабильность / Контроль |
| «Эффектный», «все спрашивают», «красивый» | Принадлежность / Внимание |
| «Удобный», «быстрый», «в моменте» | Риск / Динамика |
| «Интересный», «необычный», «разобрался» | Независимость / Познание |

**Шаг 3: Соотнесение с квадрантом**
По функции и мотивации определяем квадрант → 3 архетипа внутри.

**Шаг 4: Выбор базового архетипа**
Из трёх архетипов квадранта выбираем наиболее точный по смыслу товара.

**Шаг 5: Добавление оттеночного**
Из соседнего квадранта берём 1 архетип как «мостик».

---

## Как на самом деле

❌ **«У товара всегда есть только один правильный архетип».**
✅ В спорных категориях выбор архетипа — это выбор позиционирования. Две разные карточки одного товара могут работать на два разных архетипа.
