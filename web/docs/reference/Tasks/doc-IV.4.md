## Суть за 30 секунд

Мудрец — архетип истины и понимания. Товар «как книга на полке мыслителя»: сложная техника, образовательные курсы, аналитические приборы. Визуал: холодные тона, серо-синяя гамма, прямоугольные сетки, антиквенный шрифт. Тень: догматизм, паралич анализа.

---

## Роль

| Параметр | Описание |
|----------|----------|
| Базовая цель | Понять мир через истину |
| Стратегия | Искать информацию, анализировать, проверять |
| Теневая сторона | Догматизм, «паралич анализа», отрыв от практики |
| Квадрант | Независимость |

## Категории-носители

Книги, измерительные приборы, сложная электроника, онлайн-курсы, научное оборудование, справочные ресурсы.

## Визуальная сигнатура

| Слой | Маркеры |
|------|---------|
| **Хроматика** | Холодные тона, серый, тёмно-синий, белый, минимальный контраст, приглушённые акценты |
| **Морфология** | Прямоугольные сетки, матовые текстуры, строгая геометрия, чёткие углы |
| **Типографика** | Serif (антиква), caps, чёткая иерархия кеглей, увеличенный интерлиньяж |
| **Архитектоника** | Modular grid, centered, фокус: заголовок/информация |
| **Графика** | Графики, диаграммы, trust_badges (сертификаты, рецензии), decoration_intensity: none |
| **Сюжет** | Изолят, macro (деталь), прямой ракурс, лабораторный/библиотечный контекст |

## Речевые формулы

**Триггеры:** «Доказано», «Исследования», «Экспертиза», «Научный подход», «Факты».
**Запрещённые:** «Вау!», «Магия», «Поверьте на слово» — эмоции без доказательств подрывают доверие Мудреца.

## Мини-кейс

**Витаминный комплекс, Ozon.** Было: яркие жёлто-красные цвета, промо-стикеры «ЧУДО-ВИТАМИНЫ!». Статус: ГЕРОЙ вместо МУДРЕЦА.

Правка: холодная серо-синяя гамма, антиквенный шрифт, графики биодоступности, бейдж «3rd party testing», текст «Клинически доказанная биодоступность. Тестирование независимой лабораторией».

---

## Как на самом деле

❌ **«Мудрец — это сухая академичность».**
✅ Мудрец не сухой — он точный. Точность — это своя форма элегантности; она экономит внимание читателя.

❌ **«Инфографика убивает Мудреца».**
✅ Инфографика не враг — хаос есть враг. Структурированная инфографика (диаграмма Фейнмана) усиливает сигнал.
