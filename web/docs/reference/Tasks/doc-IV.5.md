# Документ IV.5. ЗАБОТЛИВЫЙ (Caregiver)

**Код:** IV.5
**Раздел:** IV. Атлас смыслов: 12 архетипов → Стабильность / Контроль
**Время чтения:** 3 мин

---

## Суть за 30 секунд

Заботливый — архетип милосердия и защиты. Товар «как рука на плече»: детские товары, медицинская продукция, зоотовары, домашний комфорт. Визуал: мягкий голубой, мятный, тёплый бежевый, округлые формы, текстуры шерсти. Тень: мученичество, синдром спасателя.

---

## Роль

| Параметр | Описание |
|----------|----------|
| Базовая цель | Помогать окружающим |
| Стратегия | Заботиться, делать добро, защищать слабых |
| Теневая сторона | Мученичество, синдром спасателя, выгорание |
| Квадрант | Стабильность / Контроль |

## Категории-носители

Детские товары, медицинские изделия, зоотовары, товары для дома, благотворительные продукты, средства ухода.

## Визуальная сигнатура

| Слой | Маркеры |
|------|---------|
| **Хроматика** | Мягкий голубой, мятный, тёплый бежевый, обволакивающее рассеянное освещение |
| **Морфология** | Округлые «защищающие» формы, текстуры шерсти и трикотажа, плавные переходы |
| **Типографика** | Rounded, мягкие антиквы (humanist sans), комфортный кернинг, medium weight |
| **Архитектоника** | Центрированная, средняя пустота, фокус: продукт + близость |
| **Графика** | Trust-badges (эко/качество), растительный декор, мягкие свечения (glow) |
| **Сюжет** | Lifestyle (детская/дом), hand_only (прикосновение), прямой ракурс, тёплая атмосфера |

## Речевые формулы

**Триггеры:** «Забота», «Для близких», «Безопасно», «Защита», «С любовью».
**Запрещённые:** «Доминирование», «Победа любой ценой», «Эксклюзив» — агрессия разрушает контекст заботы.

## Мини-кейс

**Корм для собак, Ozon.** Было: агрессивный красный фон, extra-bold, «ЛУЧШИЙ КОРМ! СОБАКА БУДЕТ СИЛЬНОЙ!». Статус: ГЕРОЙ вместо ЗАБОТЛИВОГО.

Правка: мятный пастельный фон, rounded шрифт, фото рук с собакой (взаимодействие), бейдж «Одобрен ветеринарами», текст «Сбалансированное питание для долгой и счастливой жизни вашего друга».

---

## Как на самом деле

❌ **«Заботливый — это только про детей и животных».**
✅ Забота универсальна: уход за пожилыми, домашние растения, сервис для клиентов — всё есть форма Заботливого.

❌ **«Мягкий стиль = отсутствие статуса».**
✅ Заботливый не просит — он имеет статус через доверие. Доверие крепче любого эксклюзива.
