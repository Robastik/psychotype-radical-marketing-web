# Документ IV.11. СЛАВНЫЙ МАЛЫЙ (Everyman)

**Код:** IV.11
**Раздел:** IV. Атлас смыслов: 12 архетипов → Принадлежность
**Время чтения:** 3 мин

---

## Суть за 30 секунд

Славный малый — архетип честности и «своего парня». Товар для ежедневной жизни: массовые продукты, бытовая химия, базовое питание. Визуал: приглушённые тона (деним, синий, коричневый), простые формы, доверительная подача. Тень: потеря индивидуальности, стадность, посредственность.

---

## Роль

| Параметр | Описание |
|----------|----------|
| Базовая цель | Принадлежать к группе |
| Стратегия | Быть «как все», культивировать эмпатию и доверие |
| Теневая сторона | Потеря индивидуальности, конформизм, «всех не угадаешь» |
| Квадрант | Принадлежность |

## Категории-носители

Масс-спрос товары повседневного потребления, базовые продукты питания, бытовая химия, бюджетная одежда, простые аксессуары, продукты для всей семьи.

## Визуальная сигнатура

| Слой | Маркеры |
|------|---------|
| **Хроматика** | Деним, приглушенный синий, тёплый коричневый, мягкий дневной свет, естественные цвета без пересвета |
| **Морфология** | Простые бытовые формы, текстуры хлопка, дерева, матовых поверхностей; ничего острого или пафосного |
| **Типографика** | Стандартные sans-serif (Helvetica, Arial), medium weight, читабельный размер, без экстры |
| **Архитектоника** | Центрированная или легкая сетка, средняя пустота, фокус: продукт в контексте |
| **Графика** | Понятные плашки, trust_badges (реальные отзывы, рейтинги), decoration_intensity: subtle |
| **Сюжет** | Lifestyle (дом/кухня/двор), прямо или лёгкий угол, full body (повседневная поза), семейный или дружеский контекст |

## Речевые формулы

**Триггеры:** «Свой», «Честный», «Для всех», «Проверенный», «Без переплат», «Как всем нужно», «Просто работает».
**Запрещённые:** «Эксклюзив», «Премиум», «Только для избранных» — эти слова разрушают доверие и отчуждают главную аудиторию.

## Мини-кейс

**Стиральный порошок, Ozon.** Было: чёрный фон, золотые рамки, текст «ПРЕМИУМ-КАЧЕСТВО. ЭКСКЛЮЗИВНАЯ ФОРМУЛА ДЛЯ ИЗБРАННЫХ!». Статус: герой вместо славного малого — слишком пафосно и чуждо для бытовой химии.

Правка: деним-синий фон, фото женщины у стиральной машины на кухне, стандартный гротеск, текст «Чисто. Просто. Без переплат. Как у всех — только лучше». Бейдж: «30 000+ отзывов, рейтинг 4.8».

---

## Как на самом деле

❌ **«Славный малый = дешёвый и некрасивый».**
✅ Это архетип доступности, а не низкого качества. IKEA, Patagonia Basic, Uniqlo — всё это славные маленькие бренды с премиальным отношением к продукту.

❌ **«Каждый товар — для „всех"».**
✅ Славный малый — это осознанная стратегия включения, а не отсутствие позиционирования. «Для всех ≠ никого нет целевой аудитории»: таргет — прагматичные покупатели, которые ценят честность выше статуса.
