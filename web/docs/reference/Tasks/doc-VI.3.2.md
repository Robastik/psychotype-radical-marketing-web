# Документ VI.3.2. Кейс: переписываем описание для Эпилептоида

**Код:** VI.3.2
**Раздел:** VI. Практика: от паспорта к продажам → VI.3 Сценарий: тексты описаний и инфографика под радикал
**Время чтения:** 3 мин

---

## Суть за 30 секунд

Кейс переписывания описания тонометра для Эпилептоида демонстрирует, как замена абстрактных фраз («высокое качество», «инновационный») на конкретные факты (ГОСТ, гарантия 5 лет, автоматическая калибровка) увеличивает конверсию. Исходный текст говорил ни на чьём языке. Переписанный текст говорит на языке Эпилептоида: порядок, надёжность, стандарты.

---

## Основной текст

### Исходный текст

**Товар:** тонометр автоматический
**Категория:** Здоровье → Тонометры
**Целевой радикал:** Эпилептоид (системность, надёжность, доверие к регламенту)

**Исходное описание:**
> «Мы предлагаем высококачественный тонометр, который подходит для всей семьи. Инновационный продукт с гарантией качества. Измеряйте давление легко и быстро!»

**Проблемы:**
| Фраза | Проблема | Почему не работает |
|-------|----------|-------------------|
| «Мы предлагаем» | Пассивная конструкция | Не цепляет, звучит как реклама |
| «Высококачественный» | Пустая фраза | Не несёт конкретики |
| «Подходит для всей семьи» | Попытка угодить всем | Эпилептоид ищет «для себя», не «для всех» |
| «Инновационный продукт» | Клише | Не несёт смысла |
| «С гарантией качества» | Абстракция | Какая гарантия? На сколько лет? |
| «Легко и быстро» | Без доказательств | За счёт чего? |

### Переписанный текст

**Переписанное описание (Эпилептоид):**
> «Надёжность в каждой детали. Тонометр [название] — точные измерения без погрешностей.
>
> **Характеристики:**
> - Метод измерения: осциллометрический
> - Диапазон: 0–280 мм рт. ст.
> - Точность: ±3 мм рт. ст.
> - Память: 90 измерений для 2 пользователей
>
> **Сертификация:**
> - ГОСТ Р ИСО 81060-2-2019
> - Регистрационное удостоверение Росздравнадзора
>
> **Гарантия:** 5 лет, бесплатная замена при браке
>
> **Комплектация:** тонометр, манжета (22–32 см), адаптер, инструкция, чехол.
>
> Закажите сейчас и получите точность, которой можно доверять.»

**Что изменилось:**
| Элемент | Было | Стало | Почему лучше |
|---------|------|-------|-------------|
| Крючок | «Мы предлагаем» | «Надёжность в каждой детали» | Цепляет Эпилептоида |
| Качество | «Высококачественный» | «Точность: ±3 мм рт. ст.» | Конкретный факт |
| Аудитория | «Для всей семьи» | «Память: 90 измерений для 2 пользователей» | Факт, не абстракция |
| Инновация | «Инновационный продукт» | «Осциллометрический метод» | Термин, не клише |
| Гарантия | «С гарантией качества» | «ГОСТ Р ИСО 81060-2-2019, 5 лет» | Конкретный документ |
| Призыв | «Измеряйте легко» | «Закажите сейчас и получите точность» | Императив + выгода |

### Инфографика под Эпилептоида

**Исходная инфографика:**
- 3 плашки: «ХИТ», «СКИДКА», «НОВИНКА»
- Яркие цвета: красный, жёлтый
- Шрифт: extra_bold

**Переписанная инфографика:**
- Таблица характеристик (метод, диапазон, точность, память)
- Бейдж «ГОСТ Р ИСО 81060-2-2019»
- Бейдж «Гарантия 5 лет»
- Иконка «2 пользователя»
- Цвета: холодная гамма, матовые тона
- Шрифт: гротеск, средний вес

**Почему лучше:**
- Таблица = язык Эпилептоида (порядок, системность)
- ГОСТ и гарантия = сигнал надёжности
- Холодная гамма = сигнал «серьёзный прибор»

## Как на самом деле

❌ **«Описание должно быть коротким и эмоциональным».**
✅ Для Эпилептоида описание должно быть **конкретным и фактологическим**. Эмоции отталкивают — факты убеждают.

❌ **«Покупатель не читает характеристики».**
✅ Эпилептоидный покупатель **читает**. Это его способ принять решение. Без характеристик он уйдёт к конкуренту.

❌ **«ГОСТ — это скучно».**
✅ Для Эпилептоида ГОСТ — это **сигнал надёжности**. «Скучно» — это для Истероида.

## Что делать на карточке

1. **Определите ведущий радикал** — из паспорта eyeCARD.

2. **Используйте таблицу слов-триггеров** — из VI.3.1. Для Эпилептоида: «надёжность», «стандарт», «точность», «гарантия», «сертификат».

3. **Замените абстракции на факты** — «высококачественный» → «точность: ±3 мм рт. ст.».

4. **Добавьте таблицу характеристик** — для Эпилептоида таблица = главный аргумент.

5. **Добавьте сертификаты** — для Эпилептоида ГОСТ = сигнал «товару можно доверять».
