# Security Policy

## Reporting a Vulnerability

Если вы обнаружили уязвимость безопасности, пожалуйста, **не** создавайте публичный Issue. 

Вместо этого отправьте сообщение на **security@eyecard.ru** с описанием:
- Описание уязвимости
- Шаги для воспроизведения
- Возможное влияние
- Предложенное исправление (если есть)

Мы благодарны за ответственное раскрытие информации и постараемся ответить в течение 48 часов.

## Security Best Practices

Для пользователей eyeCARD:

1. **Никогда** не делитесь своими учетными данными Firebase
2. **Используйте** строгие пароли для аккаунтов
3. **Обновляйте** Node.js и npm регулярно
4. **Проверяйте** `npm audit` для выявления уязвимостей

## Supported Versions

| Version | Supported          |
| ------- | -----------        |
| 0.1.x   | :white_check_mark: |

## Security Updates

Мы регулярно обновляем зависимости для устранения известных уязвимостей. 

Используйте:
```bash
npm audit fix
npm audit fix --force  # Если требуется
```

Спасибо за помощь в обеспечении безопасности eyeCARD! 🔒
