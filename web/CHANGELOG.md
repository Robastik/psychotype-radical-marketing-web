# Changelog

Все значимые изменения этого проекта будут задокументированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [0.2.0] - 2026-09-01

### Added
- Методический справочник eyeCARD (`/guide`) — динамические страницы для ~99 документов
- Индекс справочника `/guide` с карточками разделов
- Автоматическая генерация данных из Markdown (`docs/reference/Tasks/*.md`)
- Парсинг markdown-блоков: заголовки, параграфы, списки, таблицы, цитаты, код
- Компоненты справочника: `GuideLayout`, `GuideSidebar`, `GuideHeader`, `Breadcrumbs`, `TableOfContents`, `MarkdownRenderer`
- Врезки: «Суть за 30 секунд», «Как на самом деле», «Что делать», «Читайте также»
- Обработка перекрёстных ссылок `[I.1.1]` → `/guide/I.1.1`
- SEO-мета для каждого документа
- Адаптивная сетка, мобильный sidebar, print styles
- Редирект `/methodology` → `/guide`

### Changed
- Обновлен `Header.tsx`: ссылка «Методология» заменена на «Методический справочник» → `/guide`
- Обновлены `package.json` скрипты: добавлен `build:guide`, `build` теперь запускает генерацию справочника

### Fixed
- Исправлены тесты для `/methodology` после замены страницы на редирект

## [0.1.0] - 2026-08-13

### Added
- Инициальная версия проекта eyeCARD
- Структура Next.js с App Router
- Главная страница с героическим разделом
- Страницы: Методология, Политика конфиденциальности, Условия использования
- Firebase Hosting конфигурация
- TypeScript поддержка
- ESLint конфигурация
- Современные CSS переменные (OKLCH формат)
- Документация (README, LICENSE, CHANGELOG)

### Fixed
- Исправлена конфигурация Next.js для правильной работы на Firebase Hosting
- Установлены все npm зависимости

### Security
- Инициальная конфигурация безопасности Firebase
- Добавлен .env.example для управления конфиденциальными данными
